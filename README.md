# Helpers

Локальное веб-приложение для генерации тестовых данных Республики Беларусь. Данные предназначены только для тестирования, не являются реальными документами.

## Возможности

- Генераторы **паспорта РБ**, **мобильного телефона РБ**, **УНП РБ** и **IBAN РБ**
- Копирование полей в буфер обмена по кнопке и по клику на значение
- История скопированных карточек в `localStorage` (до 40 записей, без дублей)
- Сохранение настроек и результата при переключении вкладок
- Выбор хелпера через hash в URL (`#passport`, `#phone`, `#unp`, `#iban`)

## Запуск

Откройте `index.html` в браузере. Для копирования через Clipboard API удобнее локальный HTTP-сервер:

```bash
npx --yes serve .
```

Затем откройте предложенный адрес (обычно `http://localhost:3000`).

CLI-генерация паспорта:

```bash
node passport-generator.js
```

## Хелперы

### Паспорт РБ

Генерирует личный номер, серию и номер бланка, дату рождения.

| Настройка | Значения |
| --- | --- |
| Формат личного номера | Авто (по дате первой выдачи в 14 лет), классический, новый с 2012 |
| Возраст | Точный возраст, диапазон лет или годы рождения |
| Пол | Любой, мужской, женский |

Классический личный номер кодирует дату рождения, пол и регион, контрольная цифра считается по схеме 7-3-1. Новый формат (с 01.01.2012) — случайный номер вида `7xxxxxxAxxxPB` без даты рождения.

В режиме «Авто» формат выбирается по дате, когда человеку исполнилось 14 лет: до 01.01.2012 — классический, иначе — новый.

### Телефон РБ

Генерирует мобильные номера операторов A1, МТС и life:) в форматах международный, национальный, E.164 и только цифры.

Для `29` учитываются закреплённые первые цифры абонента: A1 — `1`, `3`, `6`, `9`; МТС — `2`, `5`, `7`, `8`.

### УНП РБ

Генерирует два отдельных УНП: для самозанятого и для ИП.

| Настройка | Значения |
| --- | --- |
| Регион | Любой, Минск, области |

Самозанятый — формат физлица: 9 знаков, первый — буква региона (`A` Минск, `B` Брестская, `C` Витебская, `E` Гомельская, `H` Гродненская, `K` Минская, `M` Могилёвская), второй — буква вместо цифры порядкового номера.

ИП — 9 цифр, как регистрационный номер в ЕГР: первый знак региона `1`–`7`, без букв.

Контрольная цифра в обоих форматах считается по весам 29-23-19-17-13-7-5-3 (модуль 11). Если остаток равен 10, номер не используется.

### IBAN РБ

Генерирует тестовый счёт белорусского банка в формате IBAN (28 символов).

| Настройка | Значения |
| --- | --- |
| Банк | Альфа-Банк по умолчанию, любой из списка или случайный |
| Тип счёта | Физлицо `3014`, ИП `3013`, юрлицо `3012` |
| Валюта | BYN, USD, EUR, RUB |

Структура: `BY` + контрольные цифры + первые 4 символа BIC + балансовый счёт + 16-значный индивидуальный номер. Контрольные цифры считаются по ISO 7064 MOD 97-10.

## Структура

```
index.html                 # оболочка UI
css/styles.css
js/app.js                  # навигация, форма, результаты, копирование
js/history.js              # история скопированных карточек
js/utils.js                # случайные числа и выбор из массива
js/helpers/types.js        # JSDoc-контракт хелпера
js/helpers/index.js        # реестр хелперов
js/helpers/passport.js
js/helpers/phone.js
js/helpers/unp.js
js/helpers/iban.js
passport-generator.js      # CLI-обёртка генератора паспорта
```

Скрипты подключаются как обычные `<script>` и пишут API в `globalThis.Helpers`.

## Как добавить хелпер

1. Создайте файл `js/helpers/<id>.js` с объектом `HelperDefinition`: `id`, `title`, `description`, `fields`, `resultFields`, `generate`.
2. Зарегистрируйте его в `js/helpers/index.js`.
3. Подключите скрипт в `index.html` **до** `js/helpers/index.js`.

Поля формы: `select` или `number`. Условные поля задаются через `showWhen`. Функция `generate` принимает значения формы и возвращает объект, ключи которого совпадают с `resultFields`.
